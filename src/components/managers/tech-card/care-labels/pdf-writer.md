# pdf-writer.ts — устройство файла (план §6.6)

PDF 1.4, только ASCII-синтаксис (смещения xref — в байтах), шрифтов нет: весь текст — контуры.

| объект | что | размер |
|---|---|---|
| 1 | `/Catalog` → 2 | ~50 Б |
| 2 | `/Pages`: `/Kids`, `/Count`, `/MediaBox [0 0 283.464567 85.03937]` и `/Resources /XObject` со ВСЕМИ формами файла — страницы наследуют | ~150 Б + 12 Б на сторону |
| 3, 5, … | Form XObject уникальной стороны: `/BBox [0 0 100 30]` (мм), `/Matrix [k 0 0 −k 0 H]`, k = 72/25,4 — примитивы в мм с началом сверху идут в поток как есть; поток `FlateDecode` (`fflate.zlibSync`, RFC 1950) | A ≈ 9 КБ, B ≈ 25–75 КБ |
| 4, 6, … | общий поток страниц этой стороны: `q /Sn Do Q` (без сжатия) | ~50 Б |
| далее | `/Page` на каждую страницу: `/Parent 2 0 R /Contents <поток стороны>` | ~70 Б + 20 Б xref |

Копия стороны = объект страницы + строка xref ≈ 91 Б (проба pdf.mjs, «+91 Б/стр.»), содержимое
не повторяется. Детектор проб: файл ≤ (тот же файл в одну копию) + 300 Б × страниц.

Операторы в форме (единицы — мм): `0 g 0 G 0 J` в начале; `rect` → `x y w h re f|S|B`, пунктир
`[1 1] 0 d`; `line` → `m l S`; `poly` → `m l… h f|S`; `circle` → 4 кривые Безье, незалитый — белый
внутри (`1 g`), как у SVG-читателя; `path` → `m/l/c/h` + `f` / `f*` (evenodd) / `S` / `B`, толщина
`w` и `j` (0 miter, 1 round) — в мм, потому что матрица формы масштабирует их вместе с геометрией.
`text` — throw: лента текстом не печатает. Числа — 3 знака (1 мкм), матрица и MediaBox — 6 знаков
(k до 3 знаков сдвигал бы крест на x = 95 на 0,012 мм — видно в пробе калибровки).
