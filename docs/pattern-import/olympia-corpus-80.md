# Парный прогон после переноса Olympia

На тех же 80 исходных PDF, картах размеров и ответе outline=seam сравнили состояние до и после объединения правки Olympia. База — завершённый [предыдущий прогон](final-corpus-80.md). Каждая строка контрольного CSV сопоставляет один и тот же PDF в двух сборках. Список кандидатов на геометрическую проверку определяется по финальным массивам вершин с округлением до 0,1 мм. Двусторонние расстояния для этих кандидатов вычислены из полных нативных координат. Дополнительная сверка полных нативных координат охватила все 6549 сочетаний, закрытых в обеих версиях. У 6519 все вершины совпали точно, у остальных 30 уже разошлись округлённые массивы. Скрытых округлением изменений не обнаружено. Парижский PDF входит в исходный set40, его экспериментальный патч в этот перенос не включён.

У Olympia закрытых сочетаний было 170/198, стало 168/198. В обеих версиях изделие осталось на Pieces. У C FRONT WAIST PANEL изменились вершины прежде закрытых размеров 0, 10, 12, 14, 16, 18, 20, 24, 30. Удержаны размеры 2, 26. По каждому размеру сохранён максимум отклонения обеих границ при шаге выборки до 0,5 мм. [Изменения по поимённым деталям и размерам](olympia-corpus-changes.csv). [Независимая сверка Olympia по исходным операциям](olympia-c.md).

Среди остальных 79 файлов различия статусов, вершин, причин остановки, решения проверок или содержания записанного DXF после исключения меток времени обнаружены у 12. В список вошли Asheville, Axel, Biarritz, Emma, Estoril, Kalla, Lynx, Matrix, Mendocino, Reef, Rosalina и Silverstone. Кроме двух размеров Olympia, повторно открылись размеры 6–8 и 14–16 детали G SHORTS FRONT FACING у Lynx. Для обоих версия записала причину grade-ambiguous. Для всех 80 на диске сопоставлены 17 прежних и 17 новых DXF, побайтно идентичны 0. Сравнение без меток времени выявило 0 различий по материалам. Два печатаемых текста Creation Date/Time заменялись одинаковыми маркерами. Из распакованного манифеста отдельно исключались только createdAt и gate.durationMs. Остальные теги DXF, координаты, сущности и поля манифеста сравнивались полностью. [Парное сравнение каждого документа](olympia-corpus-documents.csv).

Исходная SHA-256 сборки — `978e985c24e649bd9458cbb542b70bf1dd20c961cef6c4f2045f3b270049adbb`, новая — `cf188d6284b88dd7867d71603cd182e3491be61a3db9491b2b944c8050c0fd10`. Прошедшие файлы учитываются при выполнении обеих проверок материала: passed и manifestOk. Нативный прогон выполнен с запретом обхода Pieces. Исходные и новые снимки находятся в /private/tmp/patimport-runs/integration-final-80/corpus и /private/tmp/patimport-runs/olympia-integrated-80/corpus. Размерные карты и SHA исходных PDF находятся в input-manifest.json рядом с новым корпусом, версии и перечень изменившихся источников — в release-evidence.json и changed-source-paths.json.
