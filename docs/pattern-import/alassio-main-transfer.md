# Alassio MDF528 · G SKIRT BACK 30–32 · перенос в общую ветку

**Общая ветка воспроизвела принятый срез.** Отдельный контрольный DXF с G 26–28 и G 30–32 побайтово совпал с файлом из коммита `77302fe7b`. Максимумы по всему перечитанному G 30–32 при шаге ≤0,09 мм составили 0,009372 мм от пера к DXF и 0,009364 мм обратно.

## База и состав переноса

Сначала выполнен штатный импорт исходного MDF528 на рабочей версии `fix-pattern-pdf-open-lines`, HEAD `3d1f5f928`, с её незакоммиченными изменениями. Для обоих прогонов использован один оригинал (SHA-256 `c17db2f799c939eec9da25233bdd1ba152c53b60c23c2d0ae088f28e816728e1`) и одна карта из `integration-final-80/corpus`. Воспроизводимые версии импортера сохранены в `/private/tmp/ala30-transfer/{before,after}-runtime.mjs`. Сборки включают соседние изменения общей ветки на момент каждого чтения. В промежутке появились обработчики повторного обхода мотива и печатных стрелок долевой. Ни один из 75 других замкнутых срезов MDF528 не изменился.

Рабочая дельта из `77302fe7b` относительно `3693161cd` внесена в `src/lib/pattern-import/chains/ring-boundary.ts`. Файл совпадает с проверенной исходной версией побайтово. Для локальной маски находят по две точки пересечения на каждом кольце. Оба конца сечения должны совпасть попарно в пределах 0,035 мм. Учитываются сведения о маске, сохранённые PDF-адаптером для видимого непрозрачного штриха, идентичность файла с образцом пера, страница пары, стиль и исключение фоновых элементов. Исходные пути обоих отпечатков сохраняются в диапазонах стены. На стр. 39 пять вершин маски 8413 дают недостающую половину кольца 8419 для пары с 8430. После восстановления замкнутой стены 1324 собственная вершина на стр. 42 попадает в контур.

В `src/lib/pattern-import/chains/ring-boundary.test.ts` перенесена регрессия исходной ветки и добавлены случаи другого файла, страницы и отсутствующей подтверждённой маски. Патч только этих двух файлов относительно состояния до переноса находится в `/private/tmp/ala30-transfer/alassio-main-import.patch`. Исходники кольцевого читателя и его теста уже были незакоммиченными файлами общей ветки до начала переноса. Изменения оставлены в этом рабочем дереве.

## Перечитанный слой 1 против PDF

Из кандидатов полной точности штатные планировщик и писатель R2000 записали контрольные блоки. Проверены тип LWPOLYLINE, замыкание, единицы мм и обратный перенос раскладки. Для G 30–32 эталон прочитан прямо из операций оригинального PDF по 2 085 центрам колец и четырём парным вершинам. На каждой стороне и замыкающем звене измерено расстояние до ближайшего сегмента в обоих направлениях.

| G 30–32 | После | 0,009372 | 0,009364 | 27/11624, обратно на звене 27/11619 → 11624 |

У G 30–32 максимум до переноса приходился на точку (634,084974; 49,302392), после — (458,343891; 687,741603) мм. Кандидат изменился с 55 до 2 089 вершин, записанная полилиния — с 35 до 59. Площадь до/после 440555,73 / 440567,09 мм². Прежний обход использовал стены 1320, 1324, 1330, 1324. Новый замкнутый путь использует стену 1324.

В отдельном контрольном DXF все 59 вершин G 30–32 и все 77 вершин G 26–28 совпали в порядке записи с контролем из исходной ветки. SHA-256 итогового файла `35554118ff25fdd960c091920e8364448bd4b2a6df37535df9a3b0c8d6fca4e6`. У G 26–28 массив координат кандидата не изменился. Разница менее 0,000001 мм при чтении отдельных двухблочных DXF объясняется изменившимся началом раскладки и округлением координат при записи.

Все **75 прочих закрытых** кандидатов совпали до и после по полным последовательностям исходных координат. Все 76 закрытых срезов дополнительно записаны и перечитаны в подборках по детали. ## Команды

Из корня общей ветки, только MDF528:

```sh
id=MDF528-Alassio-Wrap-Dress-Free-Sewing-Pattern-A4-Letter-Patterns-Mood-Fabrics-Sewciety-Blog-1
pdf="$HOME/Downloads/archive 600 pcs/dresses/$id.pdf"
cards=/private/tmp/patimport-runs/integration-final-80/corpus
out=$(mktemp -d)
env -u PIECES_OPEN_PASS AUTO_GAP_OFF=1 node scripts/pattern-import/dxf-shot.mjs \
  "$pdf" --limit 0 --cards "$cards" --out "$out"

node scripts/pattern-import/alassio-g30-check.mjs "$pdf"
cmp docs/pattern-import/alassio-main-after.dxf \
  ../grbpwr-admin-client-wt-alassio30/docs/pattern-import/alassio-g30-control.dxf
./node_modules/.bin/vitest run src/lib/pattern-import/chains/ring-boundary.test.ts \
  src/lib/pattern-import/adapters/pdf/clip-fill.test.ts \
  src/lib/pattern-import/pieces/{bracketed-stamps,masked-mark-loop,clipped-mark-loop,ring-stroke-loop,fold-panel,mixed-fold-panel,source-outline-family}.test.ts
```

Для воспроизведения **именно замороженной** базовой или итоговой версии с той же картой замените первый запуск следующими командами:

```sh
runs=/private/tmp/ala30-transfer
for stage in before after; do
  mkdir -p "$out/$stage"
  env -u PIECES_OPEN_PASS AUTO_GAP_OFF=1 SHOT_CHILD="$runs/$stage-runtime.mjs" \
    node --expose-gc --max-old-space-size=8192 scripts/pattern-import/dxf-shot.mjs \
    "$pdf" "$out/$stage" "$cards/$id/case.json"
done
```

В `$runs` хранятся штатные снимки, массивы полной точности, перечитанные слои 1 и измерения PDF. Целевые проверки — **28/28 в девяти файлах**. ESLint и проверка типов кольцевого читателя с его тестом прошли.
