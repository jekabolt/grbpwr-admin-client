# Автоматическое восстановление контуров между sizes и pieces

Цель — получить правильный срез для каждой детали и каждого экспортируемого размера и снять обязательный вопрос «соедини два конца». Когда исходник допускает несколько контуров, оператор выбирает целую деталь с подсвеченным отличием. Если приемлемого контура нет, мастер показывает место и причину отказа. Ручной редактор доступен по желанию. Нерешённая деталь продолжает блокировать её экспорт.

## База сравнения

Принятые M1 и M2 дали 6350 закрытых из 7757 сочетаний «деталь × размер» на set40 и holdout40. Из 1407 оставшихся 1171 имеют исход leak. Диагностика нашла пару концов у 525, встречные касательные у 139, промежуток до 12 мм у 81. В 32 случаях дополнительно были опоры с обеих сторон и отклонение перемычки от предсказания до 1,5 мм. Это отбор для испытания. Число успешных ремонтов можно получить только из повторной заливки. Число запросов оператору измеряется отдельно.

M3 и M4 не дали новых контуров. Чтение напечатанных размерных групп у Axel, Cher и Verona отдельно дало +40, без дополнительных экспортов целых изделий. Для каждого нового изменения снимать парное сравнение на одном рабочем дереве с одинаковыми картами размеров. Подробности в [журнале](open-lines-journal.md).

## Локальное замыкание

1. Зафиксировать исходы по файлу, детали, размеру, старой карточке UI, фигуре среза и записанному DXF. Отличать отсутствие стенок у вытекшей заливки от отсутствия размерных штрихов в исходнике.
2. После обычной заливки и восстановления рассмотреть собственные концы данного размера и общие кромки возле места утечки. Учитывать полные исходные цепочки, назначение линии, направление продолжения и соседние подтверждённые контуры.
3. Проверить каждую перемычку изолированно повторной заливкой. Принимать только полностью замкнувшуюся деталь с подтверждённой принадлежностью линии, корректной геометрией и вложенностью. Результат не должен менять уже закрытые контуры. Хранить происхождение добавленного отрезка.
4. Одинаковые геометрические результаты объединить. Единственный подтверждённый контур принять автоматически. Несколько допустимых показать целиком для выбора. При отказе оставить причину. После изменения исходных назначений пересчитать. Проверять, что повторный вход в pieces не добавляет второй правки.

## Как получить больший выигрыш

Исследования разных семейств вести параллельно. Каждое производственное правило описывает механизм восстановления по данным PDF: видимости штриха, легенде, принадлежности перу, повтору на плитках или геометрии продолжения. Идентификаторы изделий, деталей и операций использовать в проверочных материалах. При совпадении причины у нескольких исполнителей один реализует общий обработчик, остальные независимо проверяют его на других исходниках. Для оценки переносимости проверять как минимум положительный и похожий неоднозначный пример, затем измерять эффект на тех же 80 PDF. Поддержку механизма на новых изделиях указывать только в пределах фактически проведённых проверок.

Приоритет с 23 ноября — сократить 1162 открытых сочетания на фиксированной базе material-integrated-80. В 75 семействах с пятью и более открытыми размерами сосредоточено 641 сочетание. Первичная метрика — сколько реальных открытых срезов закрыто по оригиналу с сохранением корректных прежних контуров. Удалённые ложные детали, новые детали и уточнения уже закрытых срезов учитывать отдельно. Параллельно с проверками Cursor на Kalla, Madison и Opal исследовать Venice MDF477 J POCKETS (18 открытых) и Memoir MDF364 I SKIRT FRONT и K SKIRT (по 18). Эти числа задают объём исследования. Приоритет следующего исправления определять по повторяемости доказанной причины на остальных снимках.

2. **Восстанавливать деталь по исходным путям для всей группы размеров.** Использовать существующие обработчики полных замкнутых путей, печатных диапазонов и полигонов по легенде. У рамки, линии размещения и конкурирующего пера должна сохраняться собственная роль. При нескольких циклах проверить различающиеся участки против оригинала.
3. **Наследовать точную фигуру внутри установленной размерной группы.** Напечатанный диапазон задаёт группу напрямую. Второй проверенный случай — совпадающие крайние контуры и согласующиеся видимые линии промежуточного размера, как Cher K30. Если принадлежность полностью неотрисованного размера к группе установлена, копировать координаты эталона и записывать основание. Для размеров с отдельными отличающимися линиями использовать эталон, чтобы найти свой цикл. На Nob Hill A по собственным линиям PDF подтверждены восемь размеров от S до 5XL, включая 2XL, 3XL и 4XL. Для замкнутого XS ещё требуется сверка с оригиналом.
4. **Сначала измерить охват на сохранённом корпусе.** Для каждого открытого сочетания посчитать, есть ли полный исходный путь, единственный составной цикл, общая фигура с доказанной группой или несколько конкурирующих вариантов. Результат свести по детали и изделию. Первой брать повторяющуюся причину, устранение которой проводит больше файлов через Pieces. Для доведения до записи первым проверить Savannah J размера 00 по напечатанной маркировке сгиба с использованием опыта Colleen F.
5. **Приёмка на обычном пути PDF → DXF.** Проверить исходник в обе стороны по всему периметру и перечитать записанный срез. Учитывать отдельно новые подтверждённые контуры, изделия, прошедшие Pieces без ручной правки, и дополнительные изделия, прошедшие все блокирующие проверки записи. Изменения уже закрытых контуров сверять с исходником, как при устранении неверного угла Colleen. Сравнить set40 и holdout40 отдельно на одной интегрированной версии. До этого результаты отдельных прогонов не складывать в прогноз.

1. Сгруппировать отказы по семье, размеру и месту на периметре. Для каждой повторяющейся группы проверить исходное перо, легенду, роль линии и продолжение на соседнем листе. Короткая дистанция до краски сама по себе не устанавливает принадлежность.
2. Проверить предполагаемое назначение исходного штриха в обычном импортере до введения нового правила. Считать полностью восстановленные контуры. Сравнить все ранее замкнутые соседние размеры и отдельно считать дополнительные экспорты. Первая очередь — группы с несколькими затронутыми размерами и изделия в одной исправимой причине от готового DXF.
3. Для крайних размеров использовать [список опор](reference-anchor-candidates.csv). Обнаружение внешней опоры на исходнике ещё не гарантирует восстановления промежуточных размеров. На Verona одна новая опора дала один размер, четыре печатные группы дали пятнадцать.
4. Проверочные примеры из смежной работы: Ventura J через плитки I4/I5 (восемь размеров в отдельном контрольном DXF); Colleen G30 (переход на соседа при формально замкнутом кольце); Colleen F (ось сгиба после замыкания); Sherwood (логотип); Harper (край плитки). | --- | --- | --- |
| Срез напечатан, при чтении распался на фрагменты | Проследить собственный штрих размера через пунктир, маску или стык листов. Соединить фрагменты с согласованным продолжением. | Указать страницы и операции, проверить видимость под маской и совпадение в перекрытии листов. ### Итоговый прогон и отчёт

Завершить текущий прогон на его зафиксированной версии. При переносе исправлений из отдельных рабочих деревьев сначала повторять затронутые PDF. Когда исправления объединены и контрольные примеры воспроизведены, выполнить полный штатный импорт тех же set40 и holdout40 с прежними картами размеров. Сохранить версию сборки и результаты обоих наборов отдельно.

В каждом наборе посчитать реальные разрывы, сколько из них устранено стыковкой напечатанных фрагментов и сколько потребовало дорисовки прямой, угла или дуги. Отдельно посчитать размеры, получившие целый эталон, и оставшиеся неоднозначные случаи с причинами. Опыты со специально скрытыми участками привести отдельно от результатов на реальных пропусках. Несколько вставок в одной детали учитывать по участкам, закрытую пару «деталь × размер» считать один раз.

Для каждой группы указать число изделий, впервые прошедших Pieces без ручного Close the gap, и число изделий, дошедших до apply. Для изделий с несколькими способами восстановления сохранить все основания и считать изделие один раз в общем итоге. Разобрать изменившиеся прежние срезы по оригиналу и подтвердить сохранность ранее корректных контуров и экспортов.

### Как проверять восстановление по эталону

Если одна фигура относится к группе размеров, каждый размер этой группы без отдельной отрисовки должен получить точную копию контура эталонного размера. Рисунок штриха может различаться при одинаковых координатах среза. Для Cher K проверить принадлежность промежуточного размера 30 к группе с совпадающими фигурами 28 и 32 и сохранить ссылку на исходный эталон. Частично отрисованные размеры сверять с их видимыми линиями.

Эталоном для поиска служит подтверждённый контур той же детали другого размера. Чтобы измерить точность переноса, скрываем известный целевой контур, сохраняем штрихи его размера и сравниваем восстановленную линию со скрытой в обе стороны. Из 137 таких проверок перенос всей формы вернул кольцо в 82 случаях. Оба допуска (95-й процентиль до 0,5 мм и максимум до 1,5 мм) прошли 10. В 25 случаях результат оказался ближе к опоре или соседнему размеру, чем к целевому.

Для локального пропуска 20–40 мм при согласии двух опор допуски выдержали 1960 из 1966 предложенных дуг. На настоящих разрывах поддержку двух опор для участка длиннее 12 мм нашли в 14 местах; в четырёх из них по всей дуге были близкие штрихи, принадлежность части этих штрихов оставалась неясной. Опоры помогают найти участок для сверки с исходником. Для автоматического принятия отдельно проверяем принадлежность штриха целевому размеру и замыкание всей детали. [Эксперимент со скрытыми контурами и реальными разрывами](open-lines-journal.md#19-november-2026--one-reference-local-missing-spans-and-original-pdf-strokes).

Проверочные фигуры хранить вместе с указанием детали, размера и источника геометрии. Для Verona G доступны [18 контуров банта в DXF](verona-bow-cuts.dxf), для Ventura J — [сравнение с независимо обведённым карманом](automatic-gap-source-findings.md). Для Cher K первое сравнение касается размеров 28 и 32. Размер 24 проверяется отдельно по его собственным штрихам.

### Проверка в мастере

У Estoril MDF518 для H SKIRT FRONT размеров S/M и B TOP FRONT размера 3XL нужно проверять срезы по материалу. Подпись «Cut here for lining» задаёт подкладке отдельную границу. У H она проходит на 127,382 мм от края основной ткани (стр. 35, операция 30865), у B — на 127,000 мм (стр. 11, операция 20330). На Pieces один внешний контур хранится на деталь и размер. Для приёмки перечитать шесть блоков, созданных штатным путём, и сравнить их с [независимыми эталонами FABRIC и LINING](../../../grbpwr-admin-client-wt-estoril/docs/pattern-import/estoril-material-perimeters.md). Максимальная измеренная ошибка эталонного DXF относительно PDF в обе стороны при шаге ≤0,1 мм составляет 0,058852 мм. Общая дуга каждой пары совпала в пределах 0,000001 мм. Текущий результат — 87/90, остановка Pieces, штатный DXF отсутствует. [Операции PDF и диагностика Estoril](../../../grbpwr-admin-client-wt-estoril/docs/pattern-import/estoril-source-check.md).

Проверить пустой список стенок, правильную пару концов, конкурирующий размер, общую кромку, рамку, несколько возможных контуров, повторный пересчёт и ручную правку. В мастере проверить автоматический исход, выбор вариантов и отказ. На двух наборах по 40 PDF сравнить прежние контуры, новые контуры, число обязательных действий и число полностью записанных изделий. Новые замыкания сверить с исходником, для доступных экспортов перечитать слой среза. Условие включения автоматического решения — измеримый выигрыш, отсутствие неверных новых замыканий и потери существующих корректных контуров или экспортов.

## Первый результат реализации

В Pieces добавлены повторная заливка в изоляции, сравнение итоговых контуров после обработки надсечек и выбор по полному контуру. В браузерной сборке эксперимент с перемычками включается через `VITE_PATTERN_IMPORT_AUTO_GAP=1`. До завершения проверки двух наборов автоматическое принятие перемычек по умолчанию выключено.

Для Ventura J чтение исходных кривых через границу листов в парном прогоне восстановило восемь размеров кармана. Замкнуты 18 из 18 размеров кармана и 173 из 234 контуров изделия против исходных 165. Все ранее закрытые контуры совпали с контролем с точностью отчёта 0,1 мм. Оба прогона с диагностическим пропуском открытых контуров остановились на шаге meaning. Дополнительного экспортированного изделия этот результат пока не дал. Подробности и команды воспроизведения приведены в [проверке исходных линий](automatic-gap-source-findings.md).

```sh
node scripts/pattern-import/automatic-gap-replay.mjs --try-bridges run-cold
```
