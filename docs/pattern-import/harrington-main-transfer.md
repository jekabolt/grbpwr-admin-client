# Harrington MDF502 в общей ветке

На рабочей ветке `fix-pattern-pdf-open-lines` штатный импорт MDF502 проходит Pieces: **68/70 → 70/70**. Следующая остановка — Meaning: у E POCKETS (seed 6) предложенная долевая не помещается внутри детали во всех размерах. До write импорт не дошёл, записано 0 областей, apply = 0. [Диагностический DXF с семью проверенными срезами](harrington-main-seven.dxf).

## Откуда снята база

Три независимых чтения одного оригинального PDF из `harrington-proof/paths.json` на одной карте 34–52. SHA-256 PDF: `83a30840de9184bfb0d734c61612c7ce42ae7882bf96fd8178d6994321193e1d`. Рабочее дерево общей ветки уже содержало исправления сверх HEAD `3d1f5f9287a094689940ec119e845de7691bc0e2`. Папка `/private/tmp/harrington-main-transfer` хранит снимки, исходную версию fill.ts и контрольные суммы. В каждом снимке есть собранный runtime и его SHA-256.

| Снимок | Замкнуто | Остановка | write / apply |
|---|---:|---|---|
| before, до переноса | 68/70 | Pieces, открыты A BACK 36 и E POCKETS 36. G WAISTBAND 36 уже замкнут. | 0 / 0 |
| strip, после harrington.patch | 68/70 | Все три среза 36 замкнуты. A 38 и 42 удерживает grade-ambiguous. | 0 / 0 |
| after, после дельты wt-harrington-upper | 70/70 | Pieces пройден. Meaning, E POCKETS, долевая. | 0 / 0 |

Контекст первого патча пересёкся с хуками общей ветки. В `fill.ts` добавлены только импорт `restoreTriangleStripContours` и его вызов перед `restorePrintedMotifPolygons`. Остальные вызовы и их порядок сохранены. Вторая дельта применилась напрямую. Диагностика размера 36 учитывает оба исходных состояния G36 — открытый в прежней базе и уже замкнутый в текущей.

## Сверка по срезам

Для каждого из семи срезов проверены замкнутый слой 1 и все координаты всех вершин перечитанного R12-блока. В системе локальных координат блока они точно совпали с контрольным DXF.

| Блок | Вершины | Контроль |
|---|---:|---|
| A_BACK_36 | 80 | Контроль размера 36, 840 исходных меток PDF |
| G_WAISTBAND_36 | 5 | 944 исходные метки. В базе было 944 вершины; расхождение со старым периметром ≤0,000311 мм при шаге 0,5 мм |
| E_POCKETS_36 | 6 | Контроль размера 36, 411 исходных меток PDF |
| A_BACK_38 | 1589 | Эталон верхнего поворота. По всему периметру PDF → DXF ≤0,027910 мм, обратно ≤0,028046 мм |
| A_BACK_42 | 1519 | Эталон верхнего поворота. PDF → DXF ≤0,027106 мм, обратно ≤0,027312 мм |
| A_BACK_48 | 140 | Подтверждённая сессия harrington-proof/final. PDF → срез ≤0,032014 мм, обратно ≤0,032009 мм |
| A_BACK_52 | 145 | Та же независимая сверка. PDF → срез ≤0,032014 мм, обратно ≤0,032009 мм |

Три блока 36, записанные после переноса, дали побайтово прежний контрольный DXF. Тот же результат получен для отдельного файла 38/42. Для 48/52 ранее отдельного DXF не было: контроль записан из принятой сессии `harrington-proof/final`, перечитан и сопоставлен с записью из новой сессии. Дополнительно повторена проверка исходных PDF-операций 48/52. Для A 38/42/48/52 шаг двустороннего измерения ≤0,1 мм.

**Все 63 прочих среза** совпали между общей базой и итогом по полным исходным массивам вершин. Две исходные течи закрыты. Среди пяти изменённых ранее закрытых срезов — G36 и A38/42/48/52 из таблицы.

## Воспроизведение

Свежий штатный прогон из корня общей ветки, только MDF502. Переменная OUT задаёт новый каталог; команда не использует сохранённый результат как входную геометрию.

```sh
H=/private/tmp/harrington-proof
T=/private/tmp/harrington-main-transfer
OUT=$(mktemp -d)
node scripts/pattern-import/automatic-gap-replay.mjs \
  "$H/paths.json" "$H/short.json" "$OUT" "$H/final" --files "$H/ids"

node scripts/pattern-import/check-harrington-transfer.mjs \
  "$T/before/"*Harrington* "$OUT/"*Harrington* "$H/final/"*Harrington* \
  docs/pattern-import/harrington-36.dxf \
  ../grbpwr-admin-client-wt-harrington-upper/docs/pattern-import/harrington-upper/harrington-upper.dxf "$OUT"
```

Исходные контроли и результаты по новой сессии хранятся в `$T/shared-36.json`, `$T/review.json`, `$T/upper/harrington-upper-verification.json` и `$T/transfer.json`. Штатный статус сохранён в `$T/after/*Harrington*/result.json`.

Целевые triangle-mark-loop, mixed-fold-panel и fold-panel — **9/9**. Все unit-тесты src/lib/pattern-import — **331/331**. Сборка yarn build:check прошла с NODE_OPTIONS=--max-old-space-size=6144. По корпусу запускался только MDF502.
