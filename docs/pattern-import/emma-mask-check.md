## Изменение

Читатель PDF сохраняет полный штрих для определения пера и отдельно вычисляет видимую заливку в координатах листа. Пустая видимая часть означает полностью скрытый штрих. Восстановление открытой ячейки использует центры площади видимых меток своего размерного ряда. Смежность проверяется в обоих направлениях. Свободный конец может продолжиться по прямой только при единственном взаимном выборе. Обход должен посетить все видимые метки один раз, вернуться в начало, окружить единственную затравку и пройти проверки относительно соседних размеров. Пересечение направлений в повороте принимается внутри двух обрезанных штрихов с учётом точности аппроксимации PDF. Пороги штатных проверок прежние.

При экспериментальном раннем отсечении заливок заново группировались перья всего листа. Один ранее закрытый срез сместился на 31,929 мм, а B26 получил выступ до 0,764 мм относительно линии из исходных меток. Эта реализация отброшена.

## Независимая проверка всего ряда

Для каждого из 470 идентификаторов отдельно отрисовывается исходная PDF-заливка, включая свои маски. Из её покрытия вычисляется центр площади. У всех взаимных соединений за пределами спорного угла порядок следует из двух ближайших соседей. На стр. 12 для входящей ветви порядок 9695 → 9700 → 9715 → 9710, для выходящей 9730 → 9740 → 9035 → 9040. Оси через полные метки 9695/9700 и 9035/9040 пересекаются в (532,97530; 667,81474). Контрольный полигон проходит по центрам всех 468 видимых меток и через эту вершину. Интервалы между отпечатками соединены прямыми, поэтому это проверка реконструкции пунктирной линии. Оба направления сверяются вдоль всего периметра с шагом ≤0,1 мм.

## Воспроизведение

Из корня рабочего дерева. BEFORE и AFTER указывают на session.v8.gz в каталогах документа двух штатных прогонов. В общем каталоге прогонов уровнем выше лежит собственный replay-runtime.mjs каждого прогона. PDF указывает на оригинал.

```sh
node scripts/pattern-import/source-check-emma-lining.mjs "$PDF" "$BEFORE"
FINAL_CELLS=1 node scripts/pattern-import/compare-emma-mask.mjs "$BEFORE" "$AFTER"
FINAL_CELLS=1 node scripts/pattern-import/emma-perimeter.mjs "$PDF" "$BEFORE" "$AFTER"
```

## Результат штатного прогона

Одна карта из 18 размеров, два полных чтения PDF без PIECES_OPEN_PASS. Оба прогона останавливаются на pieces. До исправления 128 закрытых и 34 открытых среза из 162, после — 129 и 33. Единственное новое замыкание — B26. У всех прежних 128 срезов после штатной финализации совпадают полные массивы вершин с исходной точностью. Площадь B24 составляет 83 635,407 мм², B26 — 90 505,784 мм², B28 — 96 930,660 мм². Файлы DXF штатно не выгружаются.

В принятом B26 ровно 468 уникальных видимых исходных меток и добавленная по двум напечатанным сторонам вершина, всего 469 вершин. Обе частичные заливки вошли в срез, обе скрытые исключены. Ряд 1627 не входит в стены. При проверке всего кольца отсутствуют пересечения, касания несмежных рёбер и развороты на предыдущий сегмент. Отклонение PDF → финальный срез 0,003372 мм, срез → PDF 0,003336 мм, от пересечения напечатанных осей до среза 0,000769 мм. Разница относительно прежней цепи пера по 95-му процентилю составляет 0,066407 мм. Ужесточённую проверку простоты повторили на нативном снимке: результат совпал по всем 469 вершинам и всем 468 исходным идентификаторам.

Для просмотра доступно [наложение спорного угла](emma-b26-mask.png).
