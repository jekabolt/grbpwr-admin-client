# Что видно в исходных путях 80 PDF

Снимки обычного импорта от 19–20 ноября 2026 года содержат 7757 сочетаний детали и размера. Из них 6390 уже закрыты. Для всех 1367 открытых сочетаний проверено, какие исходные линии можно предъявить в качестве основания для восстановления. Разбивка по всем 80 изделиям и 361 детали с открытыми размерами сохранена в [таблице CSV](source-coverage.csv). Строка `document` — итог изделия, строка `piece` — итог одной его детали.

| --- | ---: | ---: | ---: | ---: | ---: | ---: |

Для **64 сочетаний в 15 PDF** найден один геометрический кандидат. У каждого из этих изделий есть другие открытые размерные контуры. В счёт завершённых изделий этот опыт даёт **0 подтверждённых дополнительных экспортов**. Результат относится к исходным состояниям до обработки кривых Ventura, полигонов по легенде Cher и последующих исправлений заливки. Известные успехи этих доработок пересекаются с таблицей.

## Что посчитано

- Полный путь — единая обводка PDF. Все рёбра исходного пути учтены, операция замкнута либо её концы совпадают в пределах 0,05 мм. Сохранённое назначение отмечает совпадение размерного пера с образцом без конкурентов. Его надо сверить с оригинальной печатной легендой. Например, у Tulip размеры 8 и 24 на бумаге имеют одинаковый рисунок штриха. Один и тот же путь может быть сохранён несколькими диапазонами.
- Составной цикл — замкнутая собственная цепь, несколько фрагментов с единственным взаимным совпадением концов в пределах 0,05 мм, цикл исходных штрихов распознанного пера или непосредственно обведённый полигон по легенде. Для сложных пунктиров проверялись продолжения в углах, по правилам `keyedDashLoop`. Учитывался контур, который содержит только точку этой детали, имеет ненулевую площадь и не самопересекается.
- Общая фигура — контур подтверждённого печатного диапазона либо совпадающие крайние фигуры двух размерных перьев с согласующимися исходными штрихами промежуточного размера. Если одинаковую фигуру находили несколькими способами, она занимала одну ячейку.
- Конкуренция обнаружена у Sedona H Cargo Pocket 30–32. Две разные замкнутые цепи охватывают подпись, но их перья неоднозначны. У Rosalina B Front Self XS кандидат всего один, однако его перо тоже неоднозначно, поэтому ячейка попала в последний столбец.

Скан исключает рамки и отключённые оператором цепи. Случай без результата означает, что перечисленные проверки не нашли подтверждения в сохранённых назначениях. Например, исходное свидетельство для Nob Hill A/5XL и A/L получено при отдельном чтении оригинала с уточнённой легендой. Эти две ячейки в старых снимках попали в последний столбец. Пять PDF остановились до заливки, данных о контурах от них нет.

## Ближайшие к прохождению Pieces

- **Tulip** — собственные полные пути найдены для 19 из 20 открытых сочетаний. В их числе все 18 размеров A Front Bodice. В исходном состоянии для F Back Skirt 24 кандидат не найден. В последующем штатном прогоне замкнулись все 18 размеров A. Они сверены с оригинальным PDF и с полными развёрнутыми контурами в диагностическом DXF. [Проверка переда Tulip](tulip-source-outlines.md).
- **Layton** — для двух деталей найдены полные пути всех восьми размеров, всего 16 из 24 открытых сочетаний. У третьей детали (seed 5) остаются восемь отказов.
- **Savannah** — четыре полных пути из пяти открытых сочетаний G Back Sleeve. Размер 24 требует отдельной обработки полного оборота при привязке к исходной стенке. После восстановления геометрии у изделия ещё есть вопрос о сгибе.

JSON хранит исход для каждой открытой ячейки, номера страниц и идентификаторы путей для найденных фигур. Для повторения нужны состояния обычного мастера, снятые скриптом `automatic-gap-replay.mjs`.

```sh
node scripts/pattern-import/source-coverage.mjs "$CAPTURE" scripts/pattern-import/set40.txt scripts/pattern-import/holdout40.txt coverage.json
node scripts/pattern-import/source-coverage.mjs --csv coverage.json coverage.csv
```
