## 3. ТРЕБОВАНИЯ ПО СЦЕНАРИЮ РАБОТЫ (W-номера)

| № | требование |
|---|---|
| **W-1** | Сначала заполняются базовые поля в IDENTIFICATION, CLASSIFICATION, RESPONSIBLE ROLES. |
| **W-2** | Затем накидывается мудборд: картинки + колауты на них + общая заметка о желаемом дизайне. |
| **W-3** | Флэты (front / back / side; **два бока, если вещь асимметрична**; детали по желанию) генерируются во вкладке **FLAT — LINE DRAWING**: туда закидываются референсы + картинки + **обозначение, что это за часть**, и пишется общий комментарий. |
| **W-4** | В **GENERATION — FLAT** выбирается, что генерить. **Три варианта:** ① отдельно один вид (front / back / деталь); ② front+back+side **отдельными картинками**; ③ front+back+side **одной картинкой**, с возможностью потом **кропнуть её в N картинок**. |
| **W-5** | Генерации появляются во вьюшке; там можно **замаркать** флэт и добавить его себе, **выбрав вид** (например front) — он попадает в **FLAT SLOTS** согласно своей выноске: в **sides** либо в **details**. |
| **W-6** | Отдельный блок **GENERATION HISTORY**: все генерации, **пагинация**, **колапс блока**. |
| **W-7** | Должен быть способ **выбрать предыдущую генерацию**; при выборе в **INPUT — REFERENCES** показывается **наш промт**: загруженные картинки, описания и разметки — для **рерана** этой генерации. |
| **W-8** | Этап генерации можно **пропустить** и загрузить свои флэты руками. |
| **W-9** | Флэты генерятся **в растре**; для правки **переводятся в вектор**. Нужен **свой простой вектор-эдитор**: двигать кривые, удалять, **добавлять свою кривую в виде разных швов** (lockstitch, coverstitch и др. — виды швов уже описаны в макете). |
| **W-10** | Должна быть возможность **выбрать всё, что есть в FLAT SLOTS**, и делать правки по готовым флэтам: **передать их в промт-инпут уже размеченными** + добавить промт, что поменять. |
| **W-11** | Когда флэты готовы — генерится **FABRIC RENDER** из имеющихся флэтов; все нужные настройки есть в макете. |
| **W-12** | Можно **маркать 3D-рендеры как выбранные**. |
| **W-13** | **3D открывается только когда есть fabric render** (последовательность: флэты → рендер → 3D). |
| **W-14** | Во вкладке **ARTIFACTS** ставятся колауты на выбранные сгенерированные/размеченные медиа (или загруженные руками), и там **переключение между флэтами, рендерами и 3D**. |
| **W-15** | **Мудборд не уходит в генерацию.** Владелец процитировал строку прототипа дословно: «the mood, not the prompt: nothing here is sent to generation». Картинка попадает в промпт **только** явным переносом в INPUT — REFERENCES. Гарантия обязана стоять **на сервере**, а не только на экране. |
