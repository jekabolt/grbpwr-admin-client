# Полоса DESIGN — нормативные документы

Рабочие копии живут в `tmp/plans/design-band-ai/` (владелец попросил положить их именно туда).
**`/tmp` в этом репозитории под `.gitignore`**, то есть та копия не переживает ни свежий клон, ни
чужую машину. Здесь — отслеживаемый дубликат, потому что смысл этих файлов ровно в том, чтобы
ничего не потерялось.

| файл | что это |
|---|---|
| `30-OWNER-SPEC.md` | **нормативен.** Слова владельца дословно + 29 пронумерованных требований U/W/P |
| `31-GAP-BACKEND.md` | гэп по базе, контракту, серверу |
| `32-GAP-PROVIDERS.md` | гэп по поставщикам моделей |
| `33-GAP-CLIENT.md` | гэп клиента против макета `tmp/design-band/proto.html` |
| `34-PLAN.md` | синтез и принятые решения с обоснованиями |
| `35-TASKS.md` | задачи, карта параллелизма, хвосты |
| `36-DEPLOY.md` | ключи, порядок выката, ловушка 0346 на проде |

Файлы `00-`…`22-` — более ранние волны этой же полосы (прототип, контракт, первая реализация).
Они не нормативны: где они расходятся с `30-OWNER-SPEC.md`, прав `30-`.

Гейт соответствия — `node tmp/dsgprobe/qa-spec.mjs`: он читает номера требований ИЗ спецификации и
падает на потерянном, на выдуманном и на отметке `done`, указывающей в несуществующий файл.
Он тоже лежит в `tmp/` и тоже не отслеживается.
