## ГЛАВНЫЙ ФАКТ, ОПРОВЕРГАЮЩИЙ ПРЕЖНЕЕ УТВЕРЖДЕНИЕ

Я говорил владельцу: «бэкенд отдаёт генерацию целиком». **Это неверно.** RPC объявлены в прото и
классифицированы в RBAC, но **хендлеров на сервере нет**, а `Server` встраивает
`pb_admin.UnimplementedAdminServiceServer` (`internal/apisrv/admin/server.go:45`) — значит вызов
возвращает `Unimplemented`. Стор полон заглушек: `internal/store/design/wave2.go` — восемь методов,
каждый возвращает `entity.ErrDesignNotImplemented`. `INSERT INTO design_run` не существует нигде,
кроме теста.

Мой вывод был сделан из наличия строк `rpc StartDesignRun …` в `.proto`. Наличие объявления не есть
наличие реализации — проверять надо тело хендлера, а не сигнатуру.

**Следствие для беты:** кнопка GENERATE, выкаченная сегодня, возвращает `Unimplemented`. Денег она
НЕ бронирует и прогонов НЕ создаёт (моё вчерашнее предупреждение об этом тоже было неверным —
ошибка в безопасную сторону).

Работает ровно один путь: ручная загрузка → верстак → минт листа → разрез композита.

## ГЭП ПО ПОСТАВЩИКАМ

`internal/openrouter` на бете: **не разбирает картинки из ответа** (`Message.Content` — голая
строка), **не умеет отправлять картинки** (мультимодальный вход невыразим), потолок ответа 4 MiB с
**молчаливой обрезкой**, **асинхронных заданий нет**, модель по умолчанию `anthropic/claude-sonnet-5`
— то есть **P-1 закрыт уже сегодня**. Recraft, Meshy, GPT Image — **нет ничего**.

Ключи: `viper.BindEnv` явный, `AutomaticEnv` выключен — у каждой новой переменной обязан быть свой
`BindEnv` и тест. Ключи задавать **в дашборде DO**, не спекой: пуш `.do/app.yaml` выкатывает прод.

## ЧТО МЕНЯТЬ

**Миграции — следующий свободный номер 0348** (проверено по всем удалённым веткам).

- `0348_design_reference_note.sql` — `design_reference.note`, `design_run.rerun_of` (FK нет)
- `0349_design_bench_kind.sql` — **отдельным файлом**: `design_bench_slot.kind`, пересборка UNIQUE
  на `(tech_card_id, kind, exclusive_key)` — верстак становится двухосным (вид × род)
- `0350_design_layer_vector_origin.sql` — `design_edit_layer.origin`, `source_media_id` (FK media
  RESTRICT), `source_picture_id`

Ни одного `ADD CHECK` — намеренно.

**Прото:** `fix_targets[]` + `fix_slot_ids[]` + `auto_split` в `DesignRunParams` (скаляр
`fix_target` НЕ переиспользовать); геометрия в `DesignMoodCallout` и `DesignInputRef`;
`rerun_of` в `DesignRun`; `kind` в `DesignBenchSlot`, `DesignBenchSlotRef`, `DesignUploadItem`;
`origin`/`source_media_id`/`source_picture_id` в `DesignEditLayer`; `rerun_of_run_id` в
`StartDesignRunRequest`; `has_fabric_render` в ответе полосы. Новые RPC: `GetDesignRun`,
`ImportDesignVector`. Векторизацию НЕ выводить отдельным RPC — расширить словарь `design_run.kind`
значением `vector`, чтобы у денег была одна дверь.

**Каждый новый RPC — строка в `internal/rbac/rbac.go`:** RBAC fail-closed, тест краснеет на
неклассифицированном методе.

**Сервер:** тела в `wave2.go`; новый `apisrv/admin/design_run.go`; новый пакет воркера
`internal/designgen` с регистрацией в `app/app.go` **за флагом `DESIGN_GENERATION_ENABLED`**
(прецедент `ACCOUNTING_ENABLED`); мультимодальность в `openrouter` **отдельной структурой запроса**,
не превращением `Content` в `any` — на текстовом пути висит разбор тех-карты; новые `internal/recraft`
и `internal/meshy` под общим `dependency.DesignProvider`; `RegisterBatch` перестаёт хардкодить
`kind='flat'`; `composeMintPlates` **обязан фильтровать `kind='flat'`**, иначе рендер уедет на
технический лист.

**Границы транзакций:** резерв денег и вставка прогона — ОДНА SERIALIZABLE-транзакция (иначе падение
между ними подвешивает резерв навсегда); **вызов провайдера вне любой транзакции**; `claim_token`
обязан быть в `WHERE` у `CompleteRun`; байты провайдера в бакет ДО транзакции, сироты сметаются
`OrphanedMedia`-компенсацией, как в `SplitDesignPicture`.

## ЛОВУШКИ, УГРОЖАЮЩИЕ ИМЕННО ЭТИМ ПРАВКАМ

1. **`0346` — `ADD CONSTRAINT CHECK` на живой прод-таблице `tech_card_media`.** На проде ещё не
   применялся (master = 0339). Промоушен DESIGN на прод его запустит: `ADD CHECK` копирует таблицу
   целиком, а лимит 5 минут захардкожен. **Замерить таблицу до промоушена**; при риске вынуть 0346
   в тихое окно — файл заведён отдельно ровно для этого.
2. **`protojson UseProtoNames: true`.** `design_run.params`/`inputs` хранят snake_case, SQL-пути
   написаны по ним. Дефолтный protojson напишет lowerCamelCase — сторож перестанет отказывать,
   чипы цвета исчезнут, тесты не поймают (пустой результат законен).
3. **`TechCardMediaKindDictExtended = false`.** До применения 0346 **на проде** виды
   `side_l/side_r/render` отвергаются на входе провода. Флипать одну переменную, не две.
4. `PREPARE/EXECUTE/DEALLOCATE` — по одному оператору на строку; правило гейтом не проверяется,
   контейнерный тест его маскирует.
5. Только `entity.RawJSON` для JSON-колонок, никогда `json.RawMessage`.
6. Нумерация миграций: 0348 занять один раз; переименовать применённую миграцию нельзя.

## РЕШЕНИЯ, ПРИНЯТЫЕ ПО ИТОГАМ РАЗВЕДКИ

| вопрос | решение |
|---|---|
| синхронно или воркером | **воркером** — таблицы под него построены, латентность GPT Image и Meshy выходит за таймаут гейтвея, редеплой посреди запроса теряет оплаченное задание |
| один интерфейс или три пакета | один `dependency.DesignProvider` + три реализации; **редактируемый вектор и GLB через OpenRouter не отдаются** — это осознанное отступление от P-5, названное вслух |
| верстак одноосный или двухосный | **двухосный** (вид × род), иначе рендер вытесняет флэт и минт кладёт рендер на технический лист |
| слой держит SVG или штрихи | media держит исходный SVG, `strokes` — редактируемую проекцию, `source_media_id` их связывает |
| кроп автоматический или ручной | рамки от человека (уже построено); сервер может предзаполнять догадкой. Автомат не делать: неверный рез стоит платной перегенерации |
| где гейт W-13 | **на сервере**: `StartDesignRun` отказывает `threed` без непрятанного рендера; `has_fabric_render` зеркалит для интерфейса |
| реран | **сервер, по `rerun_of_run_id`** — клиентский снапшот позволил бы истории утверждать входы, которых не было |
| колауты на рендерах и на бумаге | лист остаётся техническим флэт-листом, но ARTIFACTS обязан сказать заранее, что разметка рендера на бумагу не попадёт — сейчас она теряется молча |
| `mixed_input` для сгенерированных | считать **в момент рождения** в `CompleteRun`, иначе согласие на смесь декоративно |
| воркер на прод | **инертным за `DESIGN_GENERATION_ENABLED`** |
